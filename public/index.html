让 course notes 看到你正在看的课程

首次在 Chrome / Safari 读取当前标签页时，macOS 会请求「自动化」权限。允许后就能自动检测课程；拒绝也不影响手动粘贴链接。

系统设置 → 隐私与安全性 → 自动化 → 允许 course notes 控制 Chrome / Safari
