说明

Web 版和 macOS 版有什么区别？

Web 版手动粘贴链接、结果不落盘；macOS 版自动检测前台课程、保存本地笔记、生成学科手册，并支持菜单栏/开机自启。

我的视频会上传吗？

不会。只抓取 B 站公开的文字信息；视频本身不经过本服务。总结文本会发送给你选择的 LLM（DeepSeek）。

为什么没有字幕也能总结？

会结合简介、分P、标签、弹幕与评论；有字幕时信息更完整。结果是学习辅助，不保证覆盖全部内容。
