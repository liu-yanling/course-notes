隐私政策

更新日期：2026-11-05 · 内测版

course notes 是一个本地优先的 macOS 桌面应用。我们尽量让你完全掌握自己的数据。

1. 我们保存什么

  • 视频标题、链接、简介、分P、标签、字幕、弹幕、评论等公开内容；
  • 生成的 Markdown 总结、Word 笔记、学科手册；
  • 你的设置（数据目录、轮询间隔、模型配置等）。

以上数据默认保存在你选择的本地数据目录（默认 ~/Documents/course notes）。

2. 什么会发送到外部

只有生成总结所需的文本会发送给你选择的 LLM 服务（例如 DeepSeek API 或本地 Ollama）。视频文件本身不会上传。你可以在设置中选择“本地提取”以避免发送到云端。

3. API Key

Key 优先保存在 macOS Keychain；不写入配置文件、不显示在页面、不进入日志。若 Keychain 不可用，内测版会明确提示并临时回退到本地配置。

4. 账号与追踪

内测版不需要注册账号，不包含广告 SDK，不做跨站追踪。

5. 删除数据

删除数据目录中的文件即可删除笔记；在设置中清除 Key 会同时移除 Keychain 项。
