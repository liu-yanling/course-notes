# 使用说明

## 1. 前置条件

- macOS + DeepSeek Harness Desktop（profile `desktop`）。
- 已安装市场版 `dsh-video-coursemap` 2.0.0 与 `dsh-memory-evolve`（当前机器已满足）。
- 能访问 B 站公开 API 与当前 DSH 配置的 LLM。
- 需要一个 B 站视频播放环境：推荐 **Tabbit Browser**（可精确读当前标签页）；
  Chrome/Edge/Brave/Arc 使用 History 近似；Safari 取决于自动化权限。

## 2. 安装

在工作区执行：

```sh
cd /path/to/course-notes
node apps/dsh-video-coursemap/scripts/install.mjs \
  --profile desktop \
  --workspace /path/to/course-notes
```

安装器会写 `~/.dsh/profiles/desktop/`，需要一次文件权限提升。它先备份，再覆盖插件，
并启用 `dsh-memory-evolve`。

**安装后必须完全退出并重新打开 DeepSeek Harness。**
host 插件模块在进程启动时加载，页面刷新不够。

## 3. 日常使用

### 自动模式

1. 把 B 站课程视频放在前台浏览器（Tabbit 精确；Chrome 需 30 分钟内访问过）。
2. 等待 2 个轮询（默认 30 秒）。
3. 生成后：
   - `课程知识地图/视频笔记/....docx` — 单视频知识总结；
   - `课程知识地图/<学科>/学习手册.docx` — 该学科知识地图；
   - `课程知识地图/课程总览.docx` — 全局总览；
   - 新会话 `📚 <学科>｜<标题>` — 对话中有 Word 交付卡片。
4. 同一个视频再次出现：无新文件、无新会话，保持静默。

### 手动模式

在任意 DSH 会话里：

- `查看课程助手状态` → 调用 `course_map_status`
- `处理这个视频 https://www.bilibili.com/video/BV...` → `course_map_scan({url})`
- `重新处理这个视频` → `course_map_scan({url, force:true})`
- `把最近笔记再交付一次` → `course_map_deliver`
- `重建所有 Word` → `course_map_rebuild`

## 4. 输出与状态

- 原始 Markdown：`课程知识地图/.state/notes/`、`.../.state/manuals/`
- 去重/学科/交付状态：`课程知识地图/.state/state.json`
- 日志：`课程知识地图/.state/logs/course.log`（JSONL，2MB 轮转）
- 学科目录名、视频笔记文件名会自动清洗非法字符并截断；同名视频用 BV 号区分。

## 5. dsh-memory-evolve

安装器把 profile patch 中的：

```yaml
- id: dsh-memory-evolve
  disabled: true
```

改为 `disabled: false`。重启后：

- 新交付会话的提示词要求用 `memory` 工具写 `target=key`（核心事实）与
  `target=project`（本次学习记录）；
- 后续同工作区会话会注入项目 KEY 记忆；
- 若 memory-evolve 启动异常，用备份回滚，视频笔记功能不受影响。

## 6. 常见问题

### 没有自动检测到

1. 看 `course_map_status` 的“前台”是否为浏览器。
2. Tabbit：确认当前标签页是 `bilibili.com/video/...`。
3. Chrome：History 近似方案只接受 30 分钟内访问的 B 站视频；刚打开的视频会更新
   History。若仍不触发，直接用 `course_map_scan({url})`。
4. 前台是 DSH 自己或其他应用时不会检测（符合“当前窗口”语义）。

### Word 生成失败

- 状态里看 `Python：...`；应指向 DSH 自带 Python 3.12（含 python-docx）。
- 手动执行：
  `~/.dsh/dsh-runtimes/dsh-primary-runtime/dependencies/python/bin/python3 scripts/md2docx.py ...`
- 先检查 `.state/manuals/` 是否有 Markdown；有则 `course_map_rebuild` 可重试。

### 新会话没有出现

- 状态里看“最近交付”；若 delivery failed，用 `course_map_deliver` 重试。
- 个别 DSH 版本 `agents`/`agentPresets` 服务不可用时只生成 Word；可在当前会话
  直接 `present` 文档路径。

### 想恢复市场版

```sh
node apps/dsh-video-coursemap/scripts/install.mjs --rollback backups/install-<时间>
```

然后重启 DSH。

## 7. 隐私与网络

- Chrome History 只读 `bilibili.com/video/` 行，复制到临时目录查询后立即删除。
- B 站请求只带匿名 `buvid3`，不使用用户 Cookie。
- 抓取内容会作为 LLM 提示词发送到当前 DSH 配置的模型；Word 只写本地工作区。
