# course notes · 竞品对标与前端设计决策

调研日期：2026-11-05
对标产品：**BibiGPT（BiliGPT / AI 课代表）** — https://bibigpt.co/about
参考文档：https://docs.bibigpt.co/getting-started/experience-all-in-one-ai-audio-video-learning-assistant

## 1. 为什么选 BibiGPT

- 它是国内最早、覆盖 B 站最完整的 AI 音视频总结产品之一；
- 核心场景与我们高度重叠：B 站课程 → 结构化总结 + 思维导图 + 字幕 + 笔记；
- 产品形态成熟：Web、浏览器插件、桌面端、移动端；
- 用户价值清晰：1 小时视频 → 5 分钟要点；
- 公开资料完整，适合做前端信息架构与交互对标。

## 2. BibiGPT 的核心能力（公开资料）

- 粘贴视频链接，生成带时间戳的结构化总结、全文转写、思维导图；
- 支持 B 站、YouTube、小红书、抖音、播客、本地文件等 30+ 来源；
- 可与视频内容多轮对话、二次追问、改写；
- 字幕翻译、视觉画面分析、Notion/Obsidian 联动；
- 免费试用 + 订阅制；数据默认私有，上传文件 30 天后删除；
- 左侧菜单、总结页面、账号/订阅、浏览器插件/桌面端/移动端。

## 3. 我们采用了哪些产品模式

| BibiGPT 的做法 | course notes 的落地 |
| --- | --- |
| App 式左侧导航 | 左侧深色 sidebar：主页 / 学习档案 / 设置 + 最近学习 |
| 首屏“粘贴链接”入口 | 首页 Hero：粘贴 B 站链接或课程标题，直接开始 |
| 视频主体页 | 视频头：封面、标题、学科、关键词、覆盖度 |
| 多标签结果页 | 总结 / 思维导图 / 弹幕评论 三个 tab |
| 结构化总结 | 总结 Markdown、知识点、术语、洞察、复习清单 |
| 历史/知识库 | 学习档案页：视频/学科双 tab、搜索、统计、Word 打开 |
| 设置/订阅 | 设置抽屉：轮询、LLM、数据目录、桌面、服务 |
| 免费试用 | V1 免费内测；V1.1 再上 ¥129 买断 |

## 4. 我们的差异化

- **自动检测**：BibiGPT 以“粘贴链接”为主；course notes 会观察当前前台浏览器，
  看完自动生成，不需要用户每次复制链接；
- **学科知识地图**：按学科合并成《学习手册》，更适合系统课程而不是单视频；
- **本地优先**：视频内容、弹幕、评论、Word 笔记落在本机；LLM 只发送文本；
- **Word 交付**：面向需要打印/归档/二次编辑的学习者；
- **桌面常驻**：启动后后台工作，不依赖浏览器标签页一直开着。

## 5. V1 前端改造结果

- 新 App Shell：左侧导航 + 顶栏状态 + 主内容；
- 首页 Hero：链接/标题输入，降低第一次使用门槛；
- 检测器卡片：当前窗口、轮询间隔、连续确认、最近轮询；
- 实时总结：步骤条、封面、关键词、总结/思维导图/弹幕评论 tabs；
- 学习档案：视频/学科、搜索、统计、Word 操作；
- 设置抽屉：轮询、LLM、数据目录、桌面快捷方式、停止服务；
- 视觉：暖纸色背景 + 深色 sidebar + 靛蓝强调色；无外部 CDN/框架；
- 已用 Tabbit 实测：3 个导航、3 个结果 tab、26 个思维导图节点、2 条历史，无页面错误。

## 6. 暂不照搬

- 不做 SaaS 账号/订阅/支付（V1 桌面免费内测）；
- 不做 30+ 平台，先聚焦 B 站；
- 不做视频对话/改写/视觉分析（V1.1 评估）；
- 不做浏览器插件（Chrome/Safari 自动化权限优先，插件后续）；
- 不做云端上传（本地优先是差异点，不是短板）。
