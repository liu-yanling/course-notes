# 前端使用说明（独立版）

## 启动

- 双击工作区里的 [启动课程助手.command](<../启动课程助手.command>)；或
- 双击 [课程助手.app](<../desktop/课程助手.app>)；或
- 终端运行：

~~~sh
cd /path/to/course-notes
node server/index.mjs --open
~~~

页面默认打开 http://127.0.0.1:43110；若端口被占用会自动尝试 43111–43119，
实际端口见 server/runtime.json。

不需要启动 DeepSeek Harness。服务只依赖 Node、本机 DSH 自带 Python（Word 转换）
和可用的 LLM Key（默认从 DSH 凭据读取）。

## 桌面快捷方式

当前会话的沙箱不能写 ~/Desktop，所以：

1. 双击 [创建桌面快捷方式.command](<../创建桌面快捷方式.command>)；它会以你的终端权限
   在 ~/Desktop 生成「课程助手.app」。
2. 或者双击工作区的 [课程助手.app](<../desktop/课程助手.app>)，页面右上角设置 →
   “创建桌面快捷方式”。

之后双击桌面图标即可；已运行时再次双击只会打开浏览器，不会重复启动服务。

## 页面操作

### 轮询

- 顶部开关：启动/暂停检测。暂停时服务不退出，历史仍可看。
- 轮询间隔：3–120 秒；拖动滑块、输入数字或点 5s/10s/15s/30s/60s。
  修改会立即保存并重排下一次轮询。
- 连续确认：同一视频连续出现 N 次才处理，防止切标签误触发。
- 立即检测：触发一次，不等待倒计时。
- 最近轮询：显示每次的时间、来源、判定和耗时。

### 实时总结

- 检测 → 分类 → 抓取 → 总结 → 生成 Word 的步骤会实时点亮；
- DeepSeek 模式下，总结内容会边生成边显示；
- 完成后可以打开/下载 Word，或打开输出目录；
- 手动总结：在输入框粘贴 B 站 URL（或输入标题）→ 开始总结。

### 学习档案

- “视频” tab：历史视频、学科、日期；查看/打开 Word；
- “学科” tab：学科与学习手册；
- 搜索框支持标题、学科、关键词过滤。

### 设置

- 轮询/后端/自动开始；
- LLM Provider、模型、Base URL、Key；
- “测试连接”验证 DeepSeek/Ollama；
- 创建桌面快捷方式；
- 停止服务。

## LLM

| Provider | 说明 |
| --- | --- |
| DeepSeek API | 默认；Key 来自 DSH 凭据或自定义；质量好、速度快 |
| Ollama | 本机 127.0.0.1:11434；默认 deepseek-r1:7b；较慢 |
| 本地提取 | 不调用 LLM；用简介/分P/标签/弹幕/评论生成结构化笔记 |

Key 解析顺序：

1. 页面设置里的自定义 Key；
2. 环境变量 DEEPSEEK_API_KEY；
3. ~/.dsh/.credentials.yaml 的 refs.DEEPSEEK_API_KEY。

页面、API 响应和日志不会返回 Key 原文；自定义 Key 保存在 server/config.json
（文件权限 0600）。

## 常见问题

### 页面打不开

- 看终端/desktop app 是否在运行；
- 查看 server/runtime.json 的实际端口；
- 端口被占用时会自动换端口，打开 runtime.json 里的 URL。

### 没有检测到视频

- 看页面“当前窗口”是否为浏览器；
- Tabbit：保持 B 站视频标签页在前台；
- Chrome：History 近似方案只接受 30 分钟内访问的 B 站视频，且需要 Chrome 在前台；
- 直接用手动 URL 总结最稳。

### 总结很慢或失败

- 设置里看 LLM 状态，点“测试连接”；
- 如果 DeepSeek 失败，系统会降级 Ollama，再降级本地提取；
- 本地提取不需要 Key，但内容为结构化摘要。

### Word 打不开/没有生成

- 需要 DSH 自带 Python 3.12 + python-docx；服务会自动查找；
- 页面会在 Word 生成失败时提示，但 Markdown 源仍保留在 .state/notes；
- 可用“打开目录”查看。

### 关闭服务

- 页面设置 → 停止服务；
- 或双击 [停止课程助手.command](<../停止课程助手.command>)；
- 若从 .app 启动，退出 app（Cmd+Q）也会停止服务。

### 和 DSH 插件同时运行

独立版与 DSH 插件共用 课程知识地图/ 和 state；请只开启一边轮询，避免重复处理。

## 新版界面（V1 对标改造）

### 左侧导航

- **主页**：Hero 输入、检测器、最近轮询、实时知识总结；
- **学习档案**：视频/学科切换、搜索、统计、打开 Word；
- **设置**：轮询、LLM、数据目录、通知、桌面快捷方式、停止服务。

### 首次启动

1. 选择数据目录（默认 ~/Documents/course notes）；
2. 连接模型：DeepSeek Key 保存到 macOS Keychain，或选本地提取；
3. 允许 Chrome/Safari 自动化权限（拒绝也可手动粘贴链接）。

### 总结页

- 视频封面 + 标题 + 学科 + 关键词 + 覆盖度；
- 三个 tab：总结 / 思维导图 / 弹幕评论；
- 打开 Word、下载、复制总结、打开目录。

### 调试

页面仍保留：

- 3–120 秒轮询间隔；
- 连续确认次数；
- 下次轮询倒计时；
- 最近轮询判定；
- window.__courseState 调试对象。

## 浏览器权限与任务重试

- 设置 → 浏览器检测：
  - “测试当前标签页”会读取当前 Chrome/Safari/Tabbit 标签页；
  - 权限被拒时打开“系统设置 → 隐私与安全性 → 自动化”，允许 course notes 控制浏览器；
  - 权限未开启时 Chrome 只能使用历史记录近似，页面会明确提示。
- 任务失败时：
  - 自动进入重试队列，按 30 秒 / 2 分钟 / 5 分钟退避；
  - 页面显示失败原因、第几次重试、倒计时；
  - 可“立即重试”或“忽略”；
  - 重试记录会跨 App 重启保留。
