FAQ

你可能想问。

需要登录吗？会上传我的视频吗？

不需要账号。视频、弹幕、评论和笔记留在本机；只有生成总结所需的文本会发给你选择的 LLM（DeepSeek / Ollama / 本地提取）。

为什么打开时提示“无法验证开发者”？

内测包使用 ad-hoc 签名、未做 Apple 公证。右键 app → 打开 → 仍要打开即可；或在终端执行 xattr -dr com.apple.quarantine。

支持 Windows / Intel Mac 吗？

当前只提供 Apple Silicon macOS 版；Windows 与 Intel 版本在规划中，尚未发布。

没有字幕的视频可以总结吗？

可以。会结合简介、分P、标签、弹幕与评论生成结构化笔记；有字幕时信息更完整。

我的 Key 安全吗？

Key 只保存在 macOS Keychain，不写入配置文件、不显示在页面、不进入日志。若 Keychain 不可用，内测版会提示并临时回退到本地配置。
